# gwbourgogne — School Supplies Store

A responsive static storefront for **gwbourgogne**, featuring a diverse school-supplies catalog with multiple brands and USD reference prices.

## Included
- 30 school-supply products
- 15+ brands
- Search, category filter, brand filter and price sorting
- Functional demo shopping cart
- Responsive desktop/mobile layout
- Compressed WebP brand logo
- GitHub Pages ready

## Categories
Art & Coloring, Writing, Paper & Notebooks, Classroom, Craft & Glue, Organization, Backpacks, Calculators, and Lunch & Daily.

## Pricing note
Prices are reference retail prices observed from major U.S. retailers in September 2026. Promotions, inventory and location may affect current prices. Verify retailer pricing before fulfilling real customer orders.

## Publish on GitHub Pages
Upload the contents of this ZIP to your `gwbourgogne.github.io` repository. Make sure `index.html` is at the repository root.
